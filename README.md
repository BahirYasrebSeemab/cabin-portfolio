# Bahir's Cabin

My portfolio: a wooden cabin in a deep-green jungle. My work is on the computer inside; my hobbies are tucked in the corner.

Built with React, TypeScript and Three.js (React Three Fiber). Hosted on Vercel.

```bash
npm install
npm run dev        # open http://localhost:5174
```

**Everything you need is in [`docs/`](docs/README.md)** — deploying, adding projects, changing contacts, adding 3D objects, and more.
